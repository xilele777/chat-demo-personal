# ChatGPT branding

The Blossom SVG outline is taken from OpenAI's official brand page:
https://openai.com/brand/

Source: https://images.ctfassets.net/kftzwdyauwt9/3M8rPrJsENQL5tjaDzo6SL/f0f85c8e27090123c767ac3c8237b401/Blossom_Dark.svg

Only the illustration guides and surrounding canvas were removed; the Blossom path is unchanged. Color follows the current light/dark theme.

The ChatGPT wordmark uses all seven unchanged letter outlines from the SVG component shipped by https://chatgpt.com/:
https://chatgpt.com/cdn/assets/956483.adb6c94dd2.js (module `mGT8`, viewBox `0 0 357 62`).

The reusable SVG assets and `ChatGPTBrand.tsx` contain the same outlines; neither relies on installed fonts or external resources at runtime.
