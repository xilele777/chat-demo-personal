# DeepSeek 参考报告落地记录

日期：2026-11-26（北京时间）。参考：[DeepSeek 网页机制与项目改造参考报告](../DeepSeek-网页机制与项目改造参考报告.md)。本次依据当前代码实施，报告中的网页采样行为与本项目的新实现分别说明。

## 当前架构与检查结果

本项目使用 React/Zustand 前端和可选 Cloudflare Worker/D1/R2。纯前端模式使用 DeepSeek 扩展的 Anthropic 风格协议；标准云端模式适配无状态 OpenAI Chat Completions、Responses 和 Anthropic Messages。项目自行构造当前消息分支的历史，不使用 DeepSeek 网页的 session/parent 私有接口。

## 修改位置

- 流传输和协议校验：`src/services/api/{sse,client,parseEvent,types}.ts`；消息状态：`src/services/chat/{store,reply,types,validation}.ts`。
- 模型名及文本附件估算：`worker/{upstream,anthropicStream,openaiResponses}.ts`。接入的是本项目现有公开/扩展协议，没有实现 DeepSeek 网页的 p/o/v 增量适配器。
- 用量与展示：`src/services/chat/usage.ts`、`src/components/messages/{AssistantMessage,TokenUsage}.tsx`、`src/i18n/{zh,en}.ts`。
- 回归：新增 `scripts/check-deepseek-reference.mjs` 并纳入 `pnpm test`；扩充 `scripts/check-streaming-ui.mjs`；调整现有协议转换器调用及本地集成用量断言。

## 验证与限制

本次通过前端与 Worker 类型检查、lint、完整 `pnpm test`（21 组专项）、云端及静态构建。隔离云端浏览器验收执行 `node scripts/check-cloud-ui.mjs check-streaming-ui`，它先运行真实本地 D1/R2 集成，再检查桌面/手机布局、续写累计、取消、缺最终事件的错误保存、模型名、部分用量和刷新恢复。手机截图已检查；未重新执行其余九组浏览器专项。

新增数据都是可选字段，已有历史仍可读取，不需要 D1 schema 迁移。R2 估算只用于新上传的标准文本附件；已有文件需要重新上传才能获得新元数据。该估算器仍是本项目的保守估算，图片仍使用独立预算，并非供应商精确 tokenizer 或真实物理窗口。

接口返回模型名称不能证明底层权重版本；没有统一配额数据就不能展示“无限”或具体恢复时间；供应商没有原消息恢复契约时不支持自动断流恢复。未新增摘要或附件检索，已有分支摘录与完整历史裁剪保持其原有证据边界。

实现验收阶段未部署，未访问生产数据库，未调用真实生产模型。DeepSeek 网页的 890880 预算、5 次版本额度、PoW 和私有接口没有写入本项目配置。
